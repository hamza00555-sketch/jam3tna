# واجهة تطبيق "الأشبال" — الشاشة الرئيسية

إعادة بناء دقيقة للواجهة من تصميم `Test.png`، **بدون فريم الجوال — فقط محتوى الشاشة**.

## المحتوى
- `index.html` — الواجهة كاملةً بـ HTML/CSS (RTL).
- `assets/mosque.png` — ظلّ المسجد + الهلال (مقتطع من التصميم الأصلي).
- `assets/book.png` — رسمة كتاب "مهمة اليوم".
- `assets/badge.png` — رسمة وسام اليوم.

## العرض
افتح `index.html` في أي متصفّح. عرض الشاشة محدّد بـ 412px (عرض الجوال) ويتمدّد للمنتصف.

## ملاحظة عن الخط
الخطوط العربية تُحمَّل من Google Fonts (خط **Cairo** للعناوين و**Tajawal** للنصوص)
عبر رابط `<link>` في أعلى الملف، فتأكّد من الاتصال بالإنترنت عند العرض ليظهر
الخط المدوّر مثل التصميم الأصلي تمامًا.

## ما أُعيد بناؤه
هيدر المسجد + زر الجرس + شارة النقاط · بطاقة "مهمة اليوم" + شريط التقدّم ·
زر "دخول الدرس" · بطاقة "تقدّمي اليوم" (٣ حلقات دائرية) · صف الإحصاءات
(القرآن/التجويد/السلوك) · بطاقة "وسام اليوم" · الشريط السفلي (٥ عناصر).
