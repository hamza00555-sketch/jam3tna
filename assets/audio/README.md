# ملفات الصوت

## takbeer.mp3

تكبيرات العيد — تُشغَّل تلقائياً في شاشة "عيد مبارك" يوم العيد.

**المتطلبات:**
- اسم الملف: `takbeer.mp3`
- المدة المقترحة: ٣٠–٦٠ ثانية (سيُكرَّر تلقائياً عبر `LoopMode.all`).
- جودة: 128–192 kbps mono كافية.

**كيف تضيف الملف:**
1. ضع الملف في `assets/audio/takbeer.mp3`.
2. شغّل `flutter pub get` ثم `flutter run`.

**مصادر مقترحة:**
- تسجيل خاص (موصى به).
- ملفات creative-commons من archive.org/youtube.

إن لم يكن الملف موجوداً، التطبيق يفتح شاشة العيد بدون صوت ويعرض إشعاراً
خفيفاً للأدمن بأن الملف ناقص (لا crash).
